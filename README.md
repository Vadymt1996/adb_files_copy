# ADB Two-Panel File Manager (Total Commander Style)

Двопанельний менеджер файлів для роботи зі смартфонами Android через ADB та файловою системою ПК у стилі Total Commander.

## 🚀 Основні можливості

- **Двопанельний інтерфейс (Total Commander Style)**:
  - Підтримка режимів: Телефон ⇄ ПК, Телефон ⇄ Телефон, ПК ⇄ ПК.
  - Швидка навігація, закладки дисків та системних папок (`/sdcard`, `DCIM`, `Download`, `Documents`, `Music`, `Pictures`).
  - Класичні гарячі клавіші: `Tab` (зміна панелі), `F2` (перейменування), `F5` (копіювання), `F6` (переміщення), `F7` (нова папка), `F8 / Del` (видалення), `Ctrl+A` (вибрати все).
- **Drag & Drop (Перетягування файлів)**:
  - **Внутрішній Drag & Drop**: затискання та перетягування файлів між панелями або в конкретні підпапки з контекстним меню дій (Скопіювати / Перемістити).
  - **Зовнішній Drag & Drop**: перетягування файлів та цілих папок безпосередньо з Провідника Windows у будь-яку панель (автоматичний `adb push` на телефон або копіювання на ПК).
- **Розумна передача та синхронізація**:
  - Блочне копіювання, плавний прогрес-бар, розрахунок швидкості (МБ/с) та орієнтовного часу до завершення (ETA).
  - Пропуск дублікатів (за збігом розміру файлу).
  - Опція автоматичного видалення оригіналів після успішної передачі (переміщення).
  - Можливість зупинки / скасування операції в будь-який момент.
- **Фільтрація та вкладки**:
  - Фільтри за типами: Зображення, Відео, Музика, Документи, Архіви, APK.
  - Вкладки статусу: Всі файли, Не скопійовані, До видалення (вже є на ПК).
- **Розумний аналізатор пам'яті (Space Analyzer / Ctrl+I)**:
  - 📊 Загальна статистика пам'яті смартфона (Зайнято / Вільно / Всього у ГБ та прогрес-бар).
  - 📁 **Аналіз розподілу за папками**: підрахунок розміру підпапок з візуальними псевдографічними барами (`[██████░░░░] 60%`), підтримка занурення в підпапки подвійним кліком.
  - 🐘 **Топ найважчих файлів**: швидкий пошук файлів понад 25/50/100/500 МБ або 1 ГБ з категоризацією за типами (Відео, Аудіо, Фото, Архіви, APK).
  - 🧹 **Пресети швидкого очищення**: пошук кешу ескізів (`.thumbnails`), медіа Telegram, WhatsApp, забутих `*.apk` інсталяторів, завантажень та порожніх папок.
  - ⚡ Швидкі дії над знайденими об'єктами: миттєвий перехід до папки у головному менеджері, копіювання на ПК або видалення з телефона в 1 клік.
- **Бездротове підключення (ADB over Wi-Fi)**:
  - ⚡ Швидке перемикання з USB на Wi-Fi в 1 клік (автоматичний `adb tcpip 5555`, визначення IP-адреси смартфона в локальній мережі, після чого кабель можна від'єднати).
  - 🔌 Пряме підключення за IP:портом з історією раніше використаних адрес (`wifi_history.json`).
  - 🔒 Бездротове сполучення для Android 11+ через код сполучення (`adb pair` + `adb connect`).
  - Окрема кнопка швидкого відключення від бездротового зв'язку без перезапуску програми.
- **Автодетекція смартфона**:
  - Автоматичний моніторинг підключення пристроїв через ADB, визначення моделі та статусу авторизації.

## 📋 Вимоги
- Python 3.10+
- Встановлений Android SDK Platform-Tools (`adb` у системному PATH)
- Увімкнене USB-налагодження на смартфоні
